# NeoKeys — Landing Page

Landing page de produto para um teclado magnético fictício, desenvolvida como projeto do bootcamp +PraTi.

## 🔗 Demo

[Link-Site](https://rafael-kuchla-flores.github.io/teclado-magnetico-landing/)

## ✨ Funcionalidades

- Página com identidade visual gamer/RGB (dark mode, roxo + ciano)
- Botão CTA com scroll suave até a seção de recursos
- Formulário de contato com validação nativa (HTML5)
- Consumo da API [ViaCEP](https://viacep.com.br/) para preenchimento automático de endereço
- Modal de agradecimento ao enviar o formulário
- Persistência dos contatos enviados via `localStorage`

## 🛠️ Tecnologias

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (Fetch API, DOM, localStorage)
- [live-server](https://www.npmjs.com/package/live-server) para desenvolvimento local

## 🚀 Como rodar o projeto

```bash
git clone https://github.com/rafael-kuchla-flores/teclado-magnetico-landing.git
cd teclado-magnetico-landing
npm install
npm run dev
```

## 🌿 Fluxo de branches

- `main` → versão estável do projeto
- `develop` → integração das funcionalidades
- `feature/*` → uma branch por funcionalidade, com Pull Request para `develop`
